## What Phase 1 IS (implement all of this)

A working **standalone free-chat** Assistant plugin end-to-end, WITHOUT any
kube tool-use. Chat streams tokens from Anthropic/OpenAI via the local agent
using the user's personal keys.

Implement exactly these parts of the brief:

- **Layer AG (agent)** EXCEPT the tool-loop and kube helpers:
  - `constants.py`: `AgentPath.LLM_MODELS`, `AgentPath.LLM_CHAT`,
    `EnvKey.LLM_ANTHROPIC_KEY/LLM_OPENAI_KEY/LLM_MODELS`, `DEFAULT_LLM_MODELS="[]"`,
    `PermissionKey.ASSISTANT_USE="assistant.use"`, `LlmProvider` string enum
    (`ANTHROPIC`/`OPENAI`), `LlmStreamEvent` string enum
    (`TEXT_DELTA`/`USAGE`/`DONE`/`ERROR`). (Skip `TOOL_START`/`TOOL_RESULT`,
    `ToolsNamespace`, tool-name enums, `KubectlFlag.*` — those are Phase 2.)
  - `config.py`: the three `llm_*` Settings fields.
  - `services/sse.py`: widen `encode_sse(event, payload)` to accept `str | StrEnum`
    (keep job-stream behavior unchanged).
  - `services/llm/` package: `models.py` (parse `llm_models`, `ModelSpec`, resolve
    label→provider+model_id+params, typed errors for bad JSON / unknown label /
    missing key), `provider.py` (protocol `stream(messages, model_spec, tools) ->
    AsyncIterator[event]`; in Phase 1 callers pass `tools=None`), `anthropic_provider.py`
    + `openai_provider.py` (SDK streaming: text deltas, usage, errors — tool_call
    mapping may be stubbed/unused in Phase 1), `retry.py` (transient classification
    list from the brief), `service.py` (build messages from system prompt + optional
    seed_context + history, stream SSE frames; **no tool loop in Phase 1**).
  - `routes.py`: `AssistantAuth` dep, register the 3 settings fields in
    `AGENT_SETTINGS_ENV_KEY_BY_FIELD`, `GET /llm/models` (non-secret metadata only),
    `POST /llm/chat` → `StreamingResponse` via `_build_sse_response` (no tool
    dispatch in Phase 1).
  - `schemas.py`: settings read/update with **secret masking** (`*_set` booleans in
    Read, optional key fields in Update; omit=unchanged, `""`=clear — mirror
    `jenkins_token`), plus LLM DTOs (`LlmModelInfo`, `LlmChatMessage`,
    `LlmSeedContext`, `LlmChatRequest`, and the text-delta/usage/done/error SSE
    payload models).
  - `pyproject.toml` + `uv.lock`: add `anthropic==0.116.0`, `openai==2.44.0`
    (refresh the lock).
  - `.env.example`: document the 3 `AGENT_LLM_*` vars.
  - Tests: `test_settings.py` (masking + round-trip + `""` clears), `test_llm.py`
    (model parsing incl. bad JSON/unknown label/missing key, provider selection,
    transient retry classification, streaming with a FAKE provider). **No tool-loop
    test in Phase 1.**

- **Layer FE (frontend)** — shared chat module + Assistant plugin:
  - `constants.ts`: `PluginId.ASSISTANT`, `IconName.ASSISTANT`, `AgentPath.LLM_MODELS`
    /`LLM_CHAT`, `ViewKey.ASSISTANT_CHAT`, `TabId.ASSISTANT_CHAT`, `TabTitle[...]`,
    `QueryKey.LLM_MODELS`, `LlmProvider` + `LlmStreamEvent` const objects.

  - `api/types.ts`: extend `AgentSettings`/`AgentSettingsUpdate` with the llm fields;
    add the LLM DTOs + SSE frame types.
  - `agentClient.ts`: extract a generic `streamAgentSse(...)` (keep `streamAgentCommand`

  - `core/llm/useLlm.ts` + `core/llm/ChatPanel.tsx`: the shared embeddable unit
    (model picker, message list, input, streaming text, usage/error, seed-context

  - `plugins/assistant/manifest.tsx` (order 29, OPTIONAL, BUILTIN, requiresAgent:true,
